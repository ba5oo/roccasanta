# Trullo Rocca Santa

Sito ufficiale del **Trullo Rocca Santa**, una casa vacanze situata tra gli ulivi e la pietra bianca di Ostuni, nel cuore della Puglia.

## 🌿 Descrizione
Questo sito mostra immagini, informazioni e link di prenotazione per gli ospiti che desiderano soggiornare nel trullo.  
Il design è ispirato allo stile pugliese tradizionale — semplice, luminoso e autentico.

## 🔗 Prenotazioni
Le prenotazioni sono gestite tramite Airbnb:  
👉 [Prenota su Airbnb](https://airbnb.com/h/roccasanta)

## 🧱 Struttura del sito
Il sito è composto da un singolo file HTML (`index.html`) con stile CSS integrato, facilmente modificabile.


## 🚀 Deployment
Il sito è ospitato su **Netlify**, con aggiornamenti automatici da **GitHub**.

Ogni volta che si modifica e salva (`commit`) un file su GitHub, Netlify aggiorna automaticamente il sito pubblico.

## 🧰 Come aggiornare
1. Apri `index.html` su GitHub.  
2. Clicca sull’icona della matita ✏️ per modificare.  
3. Fai le modifiche (testo, immagini, link).  
4. Scorri in basso e clicca **“Commit changes”**.  
5. Dopo pochi secondi, le modifiche saranno visibili online.
